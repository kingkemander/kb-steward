# 命名规则书（JD 00.01 规则与命名）

> 本机 965 份实测后定稿。命名不是审美问题，是**能不能被程序解析**的问题。

## 一、唯一格式

```
类别_主体_名称_日期.扩展名
```

固定 4 段，程序按 `_` 切分永远得到 4 段。

示例：

```
投标_山西某某环保科技有限公司_某项目响应文件_2026-10-12.docx
资质_山西某某环保科技有限公司_营业执照_2025-03-01.pdf
证件_张三_高级工程师职称证_2024-12-20.jpg
```

## 二、五条硬约束

| # | 约束 | 违反的后果（实测真发生） |
|---|---|---|
| 1 | 段内禁止下划线，原名里的 `_` 一律换 `-` | 出现 5 段、7 段，406/965 份段数失控 |
| 2 | 状态标记不进文件名（`【重复】`/`【待OCR】`） | 27 份方括号开头；状态变了名字跟着变 |
| 3 | 扩展名只在最末出现一次 | `xxx.jpg_2025-08.jpg`，472 份中招 |
| 4 | 一个抽屉只能有一个类别词 | `投标文件与报备台账` / `投标台账` / `投标` 并存 |
| 5 | 总长 ≤100 字符，超长先砍名称段 | 砍类别或主体会破坏可解析性 |

## 三、三段内容怎么填

**类别**：只能取抽屉词表里的词，封闭集合（示例 34 条）。新增类别要走总管理签核。

**主体**：必须用工商全称。简称走别名表补全（如 `某某` → `某某（山西）设计院有限公司`）。
填不出来就写 `主体待补`，**不许猜**。本机实测 65% 主体填不出是常态。

**名称**：这份东西是什么，不要写「最终版」「新建」「副本」。

**日期**：三级回退 —— 文件名年份 > 父目录年份 > 正文抽取。
正文日期与路径年份相差 3 年以上判为抽取错误。
**完全无线索填 `日期待补`，绝不填今天的日期**（会造成「文件是新的」假象）。

## 四、定稿必查四项

| # | 检查 | 修法 |
|---|---|---|
| 1 | 类别前缀是否统一 | 按「抽屉→前缀映射表」全部重写 |
| 2 | 抽屉是否被污染 | 人员证件/公司资质两个抽屉做反向校验：名字里有没有证件特征词 |
| 3 | 零证据件是否混进正式抽屉 | OCR 质量分 0 → 强制移 `00.03 待复核` |
| 4 | 日期是否打架 | 三级回退，冲突时以文件名为准并留痕 |

## 五、拆分建议（不强制）

一个文件含多份证明、表格与正文混排、多项目合订 —— 作为建议列出，由本人决定是否拆。
